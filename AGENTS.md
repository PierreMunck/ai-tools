# ai-tools

Personal toolbox of skills, agents and hooks for Claude Code, Codex and Mistral Vibe, with a
zero-dependency Node installer (`bin/ai-tools.mjs` → `src/`). Read `README.md` for what lands
where, `CONTRIBUTING.md` before adding content.

- Content is canonical in `skills/`, `agents/`, `hooks/`; host-specific output is generated by
  `src/hosts/<host>.mjs`. Never put host-specific files in the content folders.
- No dependencies, no build step. Node ≥ 20.11 built-ins only (`node:test`, `parseArgs`).
- `npm test` must pass; it also validates the toolbox content.
- Commits: Conventional Commits, on a branch, never on `main`.
